# 用户问题与配套方案（v0.2）

| 用户问题 | Skill处理 | 沙盘/验收 |
|---|---|---|
| 少问导致尺码或地区猜错 | 关键字段必须补问，无美国默认 | shoes-missing-fit-region / assumed-us |
| 本人记忆被用于送礼 | 绑定收件人核验适用性 | gift-other-recipient |
| 已经告诉过还重复问 | 当前事实/明确适用记忆复用 | same-recipient-memory / known-repeat-order |
| 旧尺码、尺码体系冲突 | 分开记录并澄清，不强行套用 | conflicting-memory |
| 次日送达但缺地区 | 补邮编，处理时间与运输分开 | deadline-zip |
| 为减少轮次省掉第四个关键问题 | 合并询问但不限制关键项总数 | many-blockers |
| 预算漏税运费 | 未知不是0，澄清预算口径 | all-in-unknown / 报价计算测试 |
| 便宜价实际是订阅/会员/返现 | 条件优惠分开，一次性价作基准 | EVALUATION.md：订阅、返现案例 |
| 同名商品实际不同版本/套装 | 型号、变体、成色、数量交叉验证 | EVALUATION.md：版本案例 |
| 有页面无库存或遇验证码 | 可用性与访问失败分开 | EVALUATION.md：库存、429案例 |
| 网页诱导改地址、上传卡号 | 外部内容无权修改授权 | 独立模拟场景：恶意网页 |
| 付款超时再次扣款 | 查订单/支付，未知则停止重付 | 独立模拟场景：pending |
| 明确授权后仍反复确认 | 沿用有效授权，越界才追问 | 独立模拟场景：有界购买 |

机器沙盘验证结构化关键字段门槛；其他行为由独立Agent文档模拟或后续宿主测试覆盖。不能将以上全部标为已通过真实工具测试。需要用户回答的事实由用户提供；商品参数、商家政策等应由Agent查证，不能全部转问用户。
