# Decisions with fewer turns

## Modes

Exact item: preserve model/variant; compare offers, not substitute products unless requested or unavailable.
Open selection: translate use case into requirements; resolve budget if it materially changes candidates.
Basket: check compatibility, missing accessories and cross-store costs. Three options can mean complete alternative baskets, not three arbitrary components.
Purchase: resolve bounded authorization and execute only permitted supported actions.

## Critical facts must be asked

Minimize unnecessary questions, never necessary questions. Before a personalized final recommendation or purchase, ask for every missing material requirement unless current context or authorized local memory explicitly establishes it for the same recipient and task. Group blockers, but do not impose a three-question maximum. Independent generic discovery can continue; a provisional example is not a personal recommendation.

Establish delivery country/region for any specific buying recommendation; a postal-code pattern is not proof of country. Ask ZIP/postal code where tax, delivery eligibility, deadline or all-in price comparison depends on it, not for unrelated generic discovery. For apparel/footwear establish size, sizing system, applicable men's/women's/children's chart and relevant fit measurements or brand chart when needed; width is a question only if material. For device-dependent accessories establish exact host model/specification. A number such as “150” does not establish currency or all-in scope: record amount, currency and scope separately. Do not ask users facts the agent should verify, such as merchant return policies.

Memory must be attributable, relevant and consistent. Current explicit instructions override old memory without asking the user to resolve an already resolved conflict. Ask only if the current instruction itself is ambiguous/conflicting or applicability remains uncertain. If another recipient, move, changing measurement or conflicting size systems makes memory insufficient, clarify. No universal expiry date makes preferences valid or stale. Do not persist a new address or body measurement without user direction.

## Missing facts

| Fact | Research | Purchase |
|---|---|---|
| Budget | Ask for open selection when material | Resolve against authorized ceiling |
| Destination country/ZIP | Ask country; ask ZIP when price/delivery depends on it; no default US | Resolve address securely |
| Deadline | Compare ordinary delivery without inventing urgency | Satisfy explicit deadline |
| Size/device/compatibility | Ask when choices would be invalid | Never guess |
| Color/style | Neutral provisional option if immaterial | Resolve material variant ambiguity |
| Condition | Prefer new for comparison, disclose | Used/refurbished must fit authorization |
| Membership | Public price baseline | Never enroll or assume membership |
| Brand | Compare relevant options without questionnaire | Respect whitelist/blacklist |

Example: “为避免买错，请一起告诉我鞋码及尺码体系、收货国家/邮编、总预算。我会按对应品牌尺码表核对，不默认美码或美国配送。” Continue independent research while awaiting answers. Do not proceed past a blocking dependency without its answer.

## Selection

Hard filters: exact identity, user requirements, region/compatibility, budget definition, destination and deadline, seller requirements. Unknown is not passed.
Soft criteria: use-case fit, attributable performance, all-in cost, seller evidence, returns/warranty, delivery certainty, lifecycle cost. Weight by category and user intent, not project size.

Trusted-brand mode prioritizes evidenced support, relevant reliability and authorized distribution, not fame alone. Value mode chooses sufficient capability at lower lifecycle cost, not merely lowest sticker price. Compare usable unit/yield for consumables. For electronics/appliances include material accessories, voltage/plug, support and running costs.

Preserve rating source, sample size, recency and variant relevance; do not average unlike scales. Bestseller status is a dated category/source claim, not proof of fit. Sponsorship is not quality evidence.

Stop when a defensible choice exists and further browsing is unlikely to change it, or a blocker/host resource limit is reached. State searched scope and unresolved material fields. Overlapping estimated totals mean price ranking is provisional.

Final shape: one recommendation sentence, at most three rows, one material caveat, necessary next action. Avoid preference questionnaires, repeated summaries and redundant confirmations.
